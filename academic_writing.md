## بخش ۲: جمله‌های نمونه (محاوره ↔ مقاله)

🗣 محاوره | 📄 مقاله | 🇮🇷 ترجمه فارسی


### افعال

**1. get → obtain / acquire**
- 🗣 We got the ECG signals from 50 patients.
- 📄 The ECG signals were acquired from 50 patients.
- 🇮🇷 سیگنال‌های ECG از ۵۰ بیمار به‌دست آمد.

**2. show → demonstrate / indicate**
- 🗣 The graph shows that the filter works well at high frequencies.
- 📄 The results demonstrate that the filter performs effectively at high frequencies.
- 🇮🇷 نتایج نشان می‌دهد فیلتر در فرکانس‌های بالا عملکرد مؤثری دارد.

**3. look at → examine / analyze**
- 🗣 We looked at how the noise affects the sensor.
- 📄 We examined the effect of noise on sensor accuracy.
- 🇮🇷 اثر نویز بر دقت سنسور را بررسی کردیم.

**4. use → utilize / employ**
- 🗣 We used a convolutional neural network to classify the images.
- 📄 A convolutional neural network was employed to classify the images.
- 🇮🇷 از یک شبکه عصبی پیچشی برای دسته‌بندی تصاویر استفاده شد.

**5. help → facilitate**
- 🗣 This framework helps developers write tests faster.
- 📄 This framework facilitates rapid test development.
- 🇮🇷 این چارچوب توسعه سریع تست‌ها را آسان می‌کند.

**6. build → develop / fabricate**
- 🗣 We built a low-cost EEG headset.
- 📄 A low-cost EEG headset was developed. *(hardware at chip level: fabricated)*
- 🇮🇷 یک هدست EEG کم‌هزینه ساخته شد.

**7. fix → resolve / mitigate**
- 🗣 We fixed the overfitting by adding dropout.
- 📄 Overfitting was mitigated by introducing dropout layers.
- 🇮🇷 با افزودن لایه‌های dropout، بیش‌برازش (overfitting) کاهش یافت.

**8. cut down → reduce / attenuate**
- 🗣 The low-pass filter cuts down the high-frequency noise.
- 📄 The low-pass filter attenuates high-frequency noise.
- 🇮🇷 فیلتر پایین‌گذر نویز فرکانس بالا را تضعیف می‌کند.

**9. need → require**
- 🗣 The model needs a lot of labeled data.
- 📄 The model requires a substantial amount of labeled data.
- 🇮🇷 این مدل به حجم قابل‌توجهی داده برچسب‌دار نیاز دارد.

**10. start → initiate**
- 🗣 The algorithm starts with a random weight matrix.
- 📄 The algorithm is initiated with a random weight matrix.
- 🇮🇷 الگوریتم با یک ماتریس وزن تصادفی مقداردهی اولیه می‌شود.

**11. figure out → infer / deduce**
- 🗣 From the data, we figured out that the battery drains faster at low temperature.
- 📄 From the data, we inferred that battery discharge accelerates at low temperatures.
- 🇮🇷 از داده‌ها نتیجه گرفتیم که تخلیه باتری در دمای پایین سریع‌تر می‌شود.

**12. try out → evaluate / validate**
- 🗣 We tried out the system on a real dataset.
- 📄 The system was evaluated on a real-world dataset.
- 🇮🇷 سیستم روی یک مجموعه‌داده واقعی ارزیابی شد.

**13. work / run → operate / function**
- 🗣 The circuit works at 3.3 V.
- 📄 The circuit operates at 3.3 V.
- 🇮🇷 مدار در ۳٫۳ ولت کار می‌کند.

**14. break → fail / degrade**
- 🗣 The system breaks when the input is noisy.
- 📄 The system's performance degrades under noisy input conditions.
- 🇮🇷 عملکرد سیستم با ورودی نویزی افت می‌کند.

**15. compare → benchmark**
- 🗣 We compared our model with three other models.
- 📄 We benchmarked the proposed model against three state-of-the-art methods.
- 🇮🇷 مدل پیشنهادی را با سه روش پیشرفته دیگر مقایسه کردیم.

**16. pull out → extract**
- 🗣 We pulled out the main features from the signal.
- 📄 Key features were extracted from the signal.
- 🇮🇷 ویژگی‌های اصلی از سیگنال استخراج شد.

**17. put together → integrate**
- 🗣 We put together data from the camera and the lidar.
- 📄 Data from the camera and lidar were integrated through sensor fusion.
- 🇮🇷 داده‌های دوربین و لیدار با ترکیب سنسوری یکپارچه شدند.

**18. change → modify / adjust**
- 🗣 We changed the learning rate during training.
- 📄 The learning rate was adjusted during training.
- 🇮🇷 نرخ یادگیری در حین آموزش تنظیم شد.

**19. find → identify / detect**
- 🗣 The algorithm finds tumors in MRI images.
- 📄 The algorithm detects tumors in MRI images.
- 🇮🇷 الگوریتم تومورها را در تصاویر MRI تشخیص می‌دهد.

**20. get rid of → eliminate / suppress**
- 🗣 We got rid of the baseline drift in the signal.
- 📄 Baseline drift was eliminated from the signal.
- 🇮🇷 رانش خط پایه از سیگنال حذف شد.

**21. make better → improve / optimize**
- 🗣 We made the code faster.
- 📄 The code was optimized to reduce execution time.
- 🇮🇷 کد برای کاهش زمان اجرا بهینه شد.

**22. check it's right → verify / validate**
- 🗣 We checked the results with a second dataset.
- 📄 The results were validated on an independent dataset.
- 🇮🇷 نتایج روی یک مجموعه‌داده مستقل اعتبارسنجی شد.

**23. teach the model → train**
- 🗣 We taught the model for 100 rounds.
- 📄 The model was trained for 100 epochs.
- 🇮🇷 مدل به‌مدت ۱۰۰ دوره (epoch) آموزش داده شد.

### صفت‌ها و اسم‌ها

**24. a lot of / huge → significant / substantial**
- 🗣 There was a huge drop in accuracy.
- 📄 A significant decrease in accuracy was observed.
- 🇮🇷 کاهش قابل‌توجهی در دقت مشاهده شد.

**25. fast → rapid**
- 🗣 The new chip is really fast.
- 📄 The proposed chip achieves rapid processing.
- 🇮🇷 تراشه پیشنهادی پردازش سریعی دارد.

**26. simple → straightforward**
- 🗣 The method is simple to set up.
- 📄 The method is straightforward to implement.
- 🇮🇷 پیاده‌سازی این روش ساده است.

**27. small / tiny → compact / negligible**
- 🗣 The sensor is tiny. The delay is tiny too.
- 📄 The sensor is compact. The delay is negligible.
- 🇮🇷 سنسور فشرده است. تأخیر ناچیز است.

**28. about the same → comparable**
- 🗣 Our accuracy is about the same as theirs.
- 📄 Our accuracy is comparable to that of the baseline.
- 🇮🇷 دقت ما با روش پایه قابل‌مقایسه است.

**29. about → approximately**
- 🗣 The device uses about 5 mW.
- 📄 The device consumes approximately 5 mW.
- 🇮🇷 دستگاه تقریباً ۵ میلی‌وات مصرف می‌کند.

**30. problem → issue / challenge / limitation**
- 🗣 The biggest problem is the lack of data.
- 📄 The main limitation is the scarcity of data.
- 🇮🇷 محدودیت اصلی، کمبود داده است.

**31. mistake → error / deviation**
- 🗣 The mistake in the measurement is small.
- 📄 The measurement error is small.
- 🇮🇷 خطای اندازه‌گیری کوچک است.

**32. part → component / module**
- 🗣 Each part of the system is tested separately.
- 📄 Each module of the system is tested independently.
- 🇮🇷 هر ماژول سیستم به‌طور مستقل آزمایش می‌شود.

**33. gadget → device**
- 🗣 It's a small gadget that sits on the wrist.
- 📄 It is a wearable device worn on the wrist.
- 🇮🇷 یک دستگاه پوشیدنی است که روی مچ بسته می‌شود.

**34. old → legacy / conventional**
- 🗣 The old method is slow.
- 📄 Conventional methods are computationally expensive.
- 🇮🇷 روش‌های متداول از نظر محاسباتی پرهزینه‌اند.

**35. new → novel**
- 🗣 We came up with a new way to detect arrhythmia.
- 📄 We propose a novel approach for arrhythmia detection.
- 🇮🇷 رویکرد جدیدی برای تشخیص آریتمی پیشنهاد می‌کنیم.

**36. important → critical**
- 🗣 Low latency is really important here.
- 📄 Low latency is critical in this application.
- 🇮🇷 تأخیر کم در این کاربرد حیاتی است.

**37. usually → typically**
- 🗣 Usually the signal is sampled at 360 Hz.
- 📄 The signal is typically sampled at 360 Hz.
- 🇮🇷 سیگنال معمولاً با نرخ ۳۶۰ هرتز نمونه‌برداری می‌شود.

### کلمات ربط

**38. because of → due to**
- 🗣 The system is slow because of the big model.
- 📄 The system is slow due to the large model size.
- 🇮🇷 سیستم به‌علت بزرگی اندازه مدل کند است.

**39. before / after → prior to / subsequent to**
- 🗣 We cleaned the data before training. After that, we tested it.
- 📄 The data were preprocessed prior to training. Subsequent to training, the model was tested.
- 🇮🇷 داده‌ها پیش از آموزش پیش‌پردازش شدند. پس از آموزش، مدل آزمایش شد.

**40. but → however**
- 🗣 The model is accurate, but it's slow.
- 📄 The model is accurate; however, it is computationally slow.
- 🇮🇷 مدل دقیق است؛ اما از نظر محاسباتی کند است.

**41. so → therefore / consequently**
- 🗣 The loss didn't go down, so we stopped training.
- 📄 The loss did not decrease; therefore, training was terminated.
- 🇮🇷 تابع زیان کاهش نیافت؛ بنابراین آموزش متوقف شد.

**42. also / plus → moreover / in addition**
- 🗣 The device is cheap. Plus, it's easy to use.
- 📄 The device is low-cost. Moreover, it is easy to use.
- 🇮🇷 دستگاه ارزان است. علاوه بر این، استفاده از آن آسان است.

**43. about → regarding / concerning**
- 🗣 There are some concerns about privacy.
- 📄 There are concerns regarding patient privacy.
- 🇮🇷 نگرانی‌هایی درباره حریم خصوصی بیماران وجود دارد.

**44. basically → in general / overall**
- 🗣 Basically, the method works.
- 📄 Overall, the proposed method is effective.
- 🇮🇷 در مجموع، روش پیشنهادی مؤثر است.

## بخش ۳: اشتباهات رایج در نگارش مقاله

هر مورد: ❌ جمله اشتباه ← ✅ جمله اصلاح‌شده ← 🇮🇷 ترجمه جمله صحیح ← 💡 دلیل

### الف) استفاده از زبان محاوره‌ای

**1. Contractions (کوتاه‌نویسی‌ها)**
- ❌ The model doesn't converge, and it's unstable.
- ✅ The model does not converge, and it is unstable.
- 🇮🇷 مدل همگرا نمی‌شود و ناپایدار است.
- 💡 در مقاله از شکل کوتاه (don't, it's, can't) استفاده نکنید.

**2. Phrasal verbs ساده**
- ❌ We looked into the problem and came up with a solution.
- ✅ We investigated the problem and proposed a solution.
- 🇮🇷 مسئله را بررسی کردیم و راه‌حلی پیشنهاد دادیم.
- 💡 Phrasal verbs معمولاً غیررسمی‌اند؛ معادل یک‌کلمه‌ای رسمی بیاورید.

**3. شروع جمله با And / But / So**
- ❌ But the accuracy was low. So we changed the architecture.
- ✅ However, the accuracy was low. Therefore, the architecture was modified.
- 🇮🇷 دقت پایین بود. بنابراین معماری اصلاح شد.
- 💡 جمله را با کلمات ربط رسمی شروع کنید.

**4. کلمات مبهم و کلی (thing, stuff, a lot)**
- ❌ The system does a lot of things, and there is a lot of data.
- ✅ The system performs multiple functions, and a large volume of data is available.
- 🇮🇷 سیستم چند عملکرد را انجام می‌دهد و حجم زیادی داده در دسترس است.
- 💡 `a lot of` و `thing` را با اسم یا قید دقیق جایگزین کنید.

**5. استفاده از etc. و and so on**
- ❌ We used sensors like temperature, pressure, etc.
- ✅ We used sensors such as temperature and pressure sensors.
- 🇮🇷 از سنسورهایی مانند سنسور دما و فشار استفاده کردیم.
- 💡 لیست را کامل کنید یا از such as استفاده کنید؛ etc. مبهم است.

**6. ضمیر اول شخص و لحن شخصی**
- ❌ I think the result is really great.
- ✅ The results indicate a notable improvement.
- 🇮🇷 نتایج بهبود قابل‌توجهی را نشان می‌دهد.
- 💡 از بیان نظر شخصی و قیدهای احساسی (really, very, amazing) پرهیز کنید. (توجه: we در مقالات رایج است، I کمتر.)

### ب) اشتباهات دستوری و ساختاری

**7. زمان فعل (Tense)**
- ❌ In 2020, Smith proposes a new algorithm.
- ✅ In 2020, Smith proposed a new algorithm.
- 🇮🇷 در سال ۲۰۲۰، اسمیت الگوریتم جدیدی پیشنهاد کرد.
- 💡 کار گذشته: past. حقیقت علمی: present ("Water boils at 100 °C"). نتایج خودمان: معمولاً past.

**8. Dangling modifier (توصیف‌گر معلق)**
- ❌ Using a Kalman filter, the noise was reduced by 30%.
- ✅ Using a Kalman filter, we reduced the noise by 30%. / The noise was reduced by 30% using a Kalman filter.
- 🇮🇷 با استفاده از فیلتر کالمن، نویز را ۳۰٪ کاهش دادیم.
- 💡 فاعل جمله باید همان فاعل عبارت ابتدایی باشد.

**9. جمله‌های بسیار طولانی (Run-on)**
- ❌ The data were collected and then filtered and then the features were extracted and then the classifier was trained and the results were good.
- ✅ The data were collected and filtered. Features were then extracted to train the classifier, yielding good results.
- 🇮🇷 داده‌ها جمع‌آوری و فیلتر شدند. سپس ویژگی‌ها برای آموزش دسته‌بند استخراج شد و نتایج خوبی به‌دست آمد.
- 💡 جمله را بشکنید؛ هر جمله یک ایده.

**10. Comma splice**
- ❌ The model is accurate, it is also fast.
- ✅ The model is accurate; it is also fast. / The model is accurate and fast.
- 🇮🇷 مدل دقیق است؛ همچنین سریع است.
- 💡 دو جمله مستقل را فقط با ویرگول نمی‌توان وصل کرد.

**11. Compare to / Compare with**
- ❌ Our method is good compare to the baseline.
- ✅ Our method performs better than the baseline. / Compared with the baseline, our method achieves higher accuracy.
- 🇮🇷 روش ما بهتر از روش پایه عمل می‌کند.
- 💡 `compare` فعل است، نه صفت؛ برای دو چیز هم‌نوع از compared with استفاده کنید.

### ج) اشتباهات رایج فارسی‌زبانان

**12. ترجمه‌ی تحت‌اللفظی**
- ❌ The results were gotten with MATLAB software.
- ✅ The results were obtained using MATLAB.
- 🇮🇷 نتایج با استفاده از MATLAB به‌دست آمد.
- 💡 `get` در مقاله ندارد؛ `with` برای ابزار گاهی نامناسب است، `using` بهتر است.

**13. Discuss about / Mention about / Emphasize on**
- ❌ This paper discusses about the effect of noise.
- ✅ This paper discusses the effect of noise.
- 🇮🇷 این مقاله اثر نویز را بررسی می‌کند.
- 💡 این افعال حرف اضافه نمی‌گیرند (discuss, mention, emphasize, investigate, describe).

**14. Data is / Data are**
- ❌ The data is collected from 20 subjects.
- ✅ The data were collected from 20 subjects. *(در بسیاری از ژورنال‌ها data جمع است؛ در بعضی هم مفرد پذیرفته می‌شود. در یک مقاله ثابت بمانید.)*
- 🇮🇷 داده‌ها از ۲۰ آزمودنی جمع‌آوری شد.

**15. Many / Much / A lot of و اسم‌های غیرقابل‌شمارش**
- ❌ The method needs many computation.
- ✅ The method requires substantial computation. / ...many computations.
- 🇮🇷 این روش به محاسبات زیادی نیاز دارد.
- 💡 `computation` در معنای کلی غیرقابل‌شمارش است؛ با much / substantial.

**16. Effect / Affect**
- ❌ The temperature effects the sensor accuracy.
- ✅ The temperature affects the sensor accuracy. / The effect of temperature on sensor accuracy is...
- 🇮🇷 دما بر دقت سنسور اثر می‌گذارد.
- 💡 affect = فعل، effect = اسم.

**17. Fewer / Less**
- ❌ The new design uses less components.
- ✅ The new design uses fewer components.
- 🇮🇷 طرح جدید از قطعات کمتری استفاده می‌کند.
- 💡 قابل‌شمارش: fewer؛ غیرقابل‌شمارش: less (less power).

**18. Based on / Based in**
- ❌ The system is based in deep learning.
- ✅ The system is based on deep learning.
- 🇮🇷 سیستم بر پایه یادگیری عمیق است.
- 💡 based on = مبتنی بر.

**19. Depend of**
- ❌ The accuracy depends of the sampling rate.
- ✅ The accuracy depends on the sampling rate.
- 🇮🇷 دقت به نرخ نمونه‌برداری وابسته است.
- 💡 depend on, consist of, differ from, result in.

**20. Respectively / Also و جابه‌جایی**
- ❌ The sensitivity and specificity are 95% and 92%.
- ✅ The sensitivity and specificity are 95% and 92%, respectively.
